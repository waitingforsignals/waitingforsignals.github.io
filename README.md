# Waiting for Signals

Static, single-page site for *Waiting for Signals*, an independent rider advocacy campaign asking CTA and NITA to study interlining the Brown and Orange lines on the west and south sides of Chicago's Loop. It's hosted on GitHub Pages at https://waitingforsignals.github.io/ (a user site, so `index.html`, `404.html`, and `loop_map.png` sit at the repo root), with no build step, frameworks, or trackers. Before launch, replace `FORM_URL_PLACEHOLDER` in `index.html` with the Tally form link. Every figure on the page links to its source.
